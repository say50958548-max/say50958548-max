#### 2. 📂 [육아 맞춤 예방접종 알림이 / Childcare Vaccine Notifier]
*아빠의 마음으로 모바일 환경에서 직접 개발한 자동 캘린더 생성기*
- **설명**: 아이의 생년월일을 기반으로 필수 예방접종 권장일을 자동으로 계산해 표준 iCalendar(`.ics`) 파일로 생성해 주는 파이썬 프로그램입니다.
- **주요 기능**:
  - 아기 이름 및 생년월일 기반 접종 일정 산출
  - 구글/삼성/아이폰 캘린더 연동용 `.ics` 파일 자동 내보내기
  - 모바일(Pydroid 3) 환경 독자 개발 및 파일 저장소 경로 최적화
- **Tech Stack**: Python 3, datetime, iCalendar (.ics) Specification
